# 薪酬管理制度（内部资料）

## 一、职级与薪档

公司设置 P1 至 P9 共九个专业职级，管理序列设置 M1 至 M5 五个职级。每个职级设置三档薪酬带宽，带宽宽度为百分之四十。

员工入职定级由招聘委员会根据岗位要求与候选人资历确定。职级晋升每年开展两次，分别在四月与十月。

## 二、调薪

年度调薪幅度依据上一周期绩效评级确定。绩效为 A 的员工调薪幅度上限为百分之十五，绩效为 B 的上限为百分之八，绩效为 C 的不调薪。

因市场薪酬水平变化或关键岗位保留需要进行的个别调薪，由部门提出申请，经人力资源部复核后报分管副总审批。

## 三、奖金

年终奖金基数为三个月基本工资，实际发放金额结合公司整体经营结果系数与个人绩效系数计算。

绩效为 C 的员工不发放年终奖。当年入职不满六个月的员工，年终奖按实际服务月数折算。

## 四、保密要求

本制度内容属公司内部资料，薪酬信息按"知情最小化"原则管理。员工不得向第三方透露本人或他人的薪酬信息，违反者依据《员工违纪处理办法》处理。
