# 信息安全基线要求（全员版）

## 一、账号与口令

员工口令长度不得少于十二位，且应包含大写字母、小写字母、数字与特殊字符中的至少三类。口令应每九十天更换一次，不得重复使用最近三次使用过的口令。

严禁将个人账号借予他人使用，严禁在多个系统间复用同一口令。公司统一提供企业口令管理器，员工应妥善保管主口令。

## 二、终端安全

办公终端应开启全盘加密并启用屏幕锁定，锁屏等待时间不得超过十分钟。终端应安装公司统一的终端防护软件，不得擅自卸载或禁用。

发现终端异常（如频繁弹窗、运行缓慢、出现未知进程）应立即联系 IT 部门处理，不得自行处置。

## 三、邮件与外发

对外发送包含客户信息、财务数据或技术资料的邮件前，应确认收件人范围并进行必要的脱敏。向外部邮箱批量外发附件超过二十兆字节的，须经部门负责人审批。

收到可疑邮件（含未知链接、要求提供口令、冒充领导要求转账）应通过电话核实，并转发至安全邮箱报备。

## 四、违规处理

违反上述要求的，视情节给予提醒、通报批评或纪律处分；造成数据泄露或其他严重后果的，依法追究相关责任。
